# Architecture

* **Design system** lives in `theme/hotel-central/assets/css/hc.css` (tokens, type, pills, hairlines, container-query "artboard" compositions with the reference measurements, photo grade, header/menu/footer).
  `assets/js/hc.js` (vanilla) provides masked line reveals, photo reveals, parallax, hairline path drawing, title overprints, header/menu/book bar, booking bar + calendar, carousel, contact form. `prefers-reduced-motion` disables all motion.
* **Pages are real Elementor documents** (flex containers + core widgets: heading, text-editor, image, button, icon-list, shortcode) created by `scripts/lib/pages.php` through Elementor's own document API. Text, photographs, links and order are edited in Elementor; layout/animation come from CSS classes in each element's *Advanced → CSS Classes* (e.g. `hc-title hc-lines`, `hc-rect r-center`, `hc-pill-w hc-tone-dark`). Editors must keep those classes.
* **Dynamic content** (custom post types, Polylang-translatable): *Rooms & Suites* (`hc_room`: name, summary, size, feature, display title lines, description, highlights, amenities, photo gallery, eZee room-type id), *Offers* (`hc_offer`, `[hc_offers]`), *Enquiries* (`hc_enquiry`, contact submissions). Room detail pages use `single-hc_room.php`; the Rooms page and homepage carousel read the same posts.
* **Hotel Information** (admin menu): phone, e-mail, address, Facebook, booking engine URL/action/hotel id, directions, map. Used in header, menu, footer, contact page, schema.org and the booking bar. Shortcodes `[hc_info]`, `[hc_address]`, `[hc_map]` surface it inside Elementor pages.
* **Booking**: `[hc_booking_bar]` posts (new tab) to `https://live.ipms247.com/booking/book-rooms-hotelcentralsarajevo` with the eZee field names (`eZ_chkin`, `eZ_chkout`, `eZ_Nights`, `eZ_adult`, `eZ_child`, `eZ_room`, `calformat`, `hidBodyLanguage`); room links use `roomwisedata.php?hid=…&roomtypeunkid=…`. Unchanged from the Next.js site.
* **Languages**: Polylang, URLs `/en/…` and `/bs/…` identical to the Next.js routes (same slugs in both languages; `inc/redirects.php` resolves same-slug pages per language). Menu strings, footer, booking and form labels are Polylang strings (Languages → Translations); Bosnian values are preloaded. Each page/room exists once per language and is linked as a translation.
* **SEO**: per-page title/description/social image (meta box "Search engines & sharing"), Open Graph, hreflang (Polylang), Hotel JSON-LD, sitemap (`/wp-sitemap.xml`), robots. Staging is `noindex` (Settings → Reading).
* **Redirects**: `data/redirects.json` (from `docs/audit/legacy-urls.csv`, confirmed 301 rows only) + un-prefixed → `/en/` or `/bs/` by `Accept-Language`.

# Editing guide
* **Pages** → Pages → hover the page → *Edit with Elementor*. Click any heading/text/photo/button and edit in the left panel. Do not delete the CSS classes (Advanced tab) — they carry the design. Use *Duplicate* on an existing section to add another of the same kind. Titles use a line break (`<br>`/Shift+Enter) for the editorial line split.
* **Rooms** → Rooms & Suites. Each room has an English and a Bosnian entry (language box on the right). Fields: details box + Excerpt (summary) + photographs. Order = *Order* field (Page attributes).
* **Offers** → Offers; show them anywhere with `[hc_offers]` in an Elementor *Shortcode* widget.
* **Phone, e-mail, address, booking links** → Hotel Information.
* **Menu** → Appearance → Menus (one per language, assigned to *Main menu*).
* **UI words** (Book now, Menu, footer labels, form messages) → Languages → Translations.
* **SEO** → "Search engines & sharing" box under each page/room.
* **Enquiries** from the contact form are stored under *Enquiries* and e-mailed to the Hotel Information address.

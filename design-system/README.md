# Hotel Central design system (source)

Source files for the Hotel Central Design System artifact: https://claude.ai/artifact/Tej9sCB32n1KnZdXnz1gpt

Extracted from this repository at `9e652c8`. Files are laid out exactly as the artifact stores them under `project/`:

- `project/tokens.json`: colours (two themes: the site/admin light theme and the admin dark theme), type, spacing, radius
- `project/README.md`: the brand book
- `project/components/`: static preview cards, guidelines, `bundle.css` and `index.d.ts`
- `project/assets/`: logos and decorative lines (SVG). The photographs are uploaded from `public/images/` and are not duplicated here.
- `blobs.json`: the upload ids of the assets in the artifact

Edit these files and republish to change the system. The website does not read them.

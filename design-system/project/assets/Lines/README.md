# Lines

The six decorative hairline paths from `src/components/DecorativeLine.tsx` (`linePaths`), each in a 1025×640 viewBox. They are stretched to their section with `preserveAspectRatio="none"` and a non-scaling 1px stroke.

These files use the `dark` tone, ink at 32% (`rgba(2,13,16,0.32)`), for ivory grounds. On deep or olive use white at 42%; for the sage tone use `rgba(161,170,130,0.7)`.

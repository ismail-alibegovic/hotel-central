Three-part editorial metadata row (left / centre / right with an index), set in `label` (`src/components/ui.tsx`).

- Sits above a section to frame it like a magazine page: section name on the left, place in the centre, an index number at 78.7% across.
- Below 1024px it collapses into a two-column grid.
- Props: `left` (required), `center`, `index`, `right`, `rightSub` (shown at 80% opacity).
